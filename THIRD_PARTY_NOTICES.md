package index. The archive's README identifies Jörg Tiedemann and Santhosh
Thottingal as authors and says the original OPUS-MT model is licensed under
CC BY 4.0. DianYi does not redistribute the model in this repository.

- Model index: <https://github.com/argosopentech/argospm-index>
